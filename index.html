Custom Scripting LUA Profile Editor (Rute & Kecepatan)

Skrip LUA ini menentukan kecepatan kendaraan, membatasi akses jalan sempit/gang, serta memprioritaskan atau menghindari jalan tol berdasarkan metadata tag dari OpenStreetMap (OSM).

profile.lua Language: LUA

OSM Data Processing Compiler Terminal (osrm-extract, partition, customize)

Simulasikan pemrosesan peta mentah `.osm.pbf` Indonesia menjadi struktur graf OSRM terkompresi menggunakan *Contraction Hierarchies*.

[Menunggu perintah] Klik "Jalankan Pipeline OSRM" untuk memproses data peta indonesia.osm.pbf

Docker Container & RAM Optimization

DOCKER ACTIVE
Nama Container: osrm-backend-indonesia
Metode Routing: CH (Contraction Hierarchies)
Penggunaan RAM Server: 1.2 GB / 8.0 GB
Strategi RAM Optimization:
  • Memuat data peta menggunakan flag `--mmap` untuk menghemat alokasi memori heap virtual.
  • Menggunakan algoritma *Multi-Level Dijkstra (MLD)* untuk pembaruan waktu tempuh dinamis tanpa re-kalkulasi graf utama.
  • Menyimpan cache segment jalan tersering di buffer memori L1/L2 container.

2. Scripting LUA Kustom

3. Optimasi Server & RAM
